# 点击图片能打开预览

## 产品经理

根据项目上下文，需要完善订单详情页功能，核心需求是**点击订单项目中的图片能打开预览**。以下是基于现有架构的功能列表和验收标准。

---

### **功能列表**

1.  **订单详情页完善**
    *   **订单信息展示**：显示订单号、客户、截止日期、优先级、状态、备注等。
    *   **订单项目列表**：清晰展示每个产品的名称、规格、数量、图纸、图片等信息。
    *   **关联任务列表**：显示该订单下的所有任务及其状态、负责人。
    *   **图片预览功能**：点击订单项目中的图片，弹出模态框显示大图。

2.  **图片预览组件**
    *   创建一个全局可用的图片预览模态框组件。
    *   接收图片URL，支持全屏或放大显示。
    *   提供关闭按钮和点击背景关闭的功能。

### **验收标准**

#### **1. 订单详情页**
*   **AC1.1**：访问 `/orders/:id` 路由，能正确加载并显示对应订单的完整信息。
*   **AC1.2**：订单基本信息区域正确显示 `order_number`, `deadline`, `priority`, `status`, `notes` 等字段。
*   **AC1.3**：客户信息区域（若关联）正确显示 `name`, `contact`, `phone` 等信息。
*   **AC1.4**：订单项目列表为每个 `OrderItem` 显示：`product_name`, `quantity`, `material`, `drawing_name`。
*   **AC1.5**：每个订单项目的 `image_url` 字段不为空时，在界面上显示为可点击的图片缩略图。
*   **AC1.6**：任务列表区域显示所有关联的 `OrderTask`，并展示任务名称、状态、负责人。

#### **2. 图片预览功能**
*   **AC2.1**：点击任意一个订单项目的图片缩略图，页面中央立即弹出一个模态框。
*   **AC2.2**：模态框内清晰、完整地显示被点击图片的大图（原尺寸或自适应缩放）。
*   **AC2.3**：模态框提供以下任一关闭方式：
    *   右上角有明确的关闭按钮（“X”）。
    *   点击模态框背景（图片外部的遮罩层）即可关闭。
    *   按下键盘 `ESC` 键可关闭。
*   **AC2.4**：关闭模态框后，页面恢复至点击前的状态，无页面跳转或刷新。
*   **AC2.5**：预览组件在 `Vue3` 中作为可复用组件（如 `ImagePreviewModal.vue`）实现，逻辑与视图分离。

#### **3. 技术实现约束**
*   **前端**：在 `OrderDetail.vue` 中集成图片预览组件。图片数据来源于已获取的 `OrderItem.image_url`。
*   **后端**：无需新增API。`GET /api/orders/:id` 接口需确保返回的订单数据中包含其关联的 `items`（订单项目）和 `tasks`（任务），以及 `items` 中的 `image_url` 字段。
*   **数据库**：确保 `order_items` 表的 `image_url` 字段存储了有效的、可公开访问（或带有权限Token）的图片链接。

```typescript
// server/src/index.ts
import express from 'express'
import cors from 'cors'
import dotenv from 'dotenv'
import { supabase } from './supabase'

dotenv.config()

const app = express()
const PORT = process.env.PORT || 3001
const VALID_ROLES = ['admin', 'office', 'cnc_program', 'cnc_machine', 'print_3d', 'workshop']

app.use(cors())
app.use(express.json())

// 验证 JWT 并检查管理员权限
async function requireAdmin(req: express.Request, res: express.Response, next: express.NextFunction) {
  const authHeader = req.headers.authorization
  if (!authHeader?.startsWith('Bearer ')) {
    return res.status(401).json({ error: '未授权' })
  }

  const token = authHeader.slice(7)
  const { data: { user }, error } = await supabase.auth.getUser(token)

  if (error || !user) {
    return res.status(401).json({ error: '无效的令牌' })
  }

  const { data: profile } = await supabase
    .from('profiles')
    .select('role')
    .eq('id', user.id)
    .single()

  if (!profile || profile.role !== 'admin') {
    return res.status(403).json({ error: '需要管理员权限' })
  }

  ;(req as any).userId = user.id
  next()
}

// 验证 JWT（不限制管理员权限）
async function requireAuth(req: express.Request, res: express.Response, next: express.NextFunction) {
  const authHeader = req.headers.authorization
  if (!authHeader?.startsWith('Bearer ')) {
    return res.status(401).json({ error: '未授权' })
  }

  const token = authHeader.slice(7)
  const { data: { user }, error } = await supabase.auth.getUser(token)

  if (error || !user) {
    return res.status(401).json({ error: '无效的令牌' })
  }

  ;(req as any).userId = user.id
  next()
}

app.get('/api/health', (_req, res) => {
  res.json({ status: 'ok', timestamp: new Date().toISOString() })
})

// 创建用户（管理员）
app.post('/api/users', requireAdmin, async (req, res) => {
  const { email, password, username, role, tracker_code } = req.body

  if (!email || !password || !username || !role) {
    return res.status(400).json({ error: '缺少必填字段' })
  }

  if (!VALID_ROLES.includes(role)) {
    return res.status(400).json({ error: '无效的角色' })
  }

  try {
    // 创建用户账户
    const { data: authUser, error: authError } = await supabase.auth.admin.createUser({
      email,
      password,
      email_confirm: true
    })

    if (authError || !authUser.user) {
      return res.status(400).json({ error: authError?.message || '创建用户失败' })
    }

    // 创建用户档案
    const { error: profileError } = await supabase
      .from('profiles')
      .insert({
        id: authUser.user.id,
        username,
        role,
        tracker_code: tracker_code || null
      })

    if (profileError) {
      // 如果创建档案失败，删除已创建的用户账户
      await supabase.auth.admin.deleteUser(authUser.user.id)
      return res.status(400).json({ error: profileError.message })
    }

    res.status(201).json({
      message: '用户创建成功',
      user: {
        id: authUser.user.id,
        email: authUser.user.email,
        username,
        role,
        tracker_code
      }
    })
  } catch (error) {
    console.error('创建用户错误:', error)
    res.status(500).json({ error: '服务器内部错误' })
  }
})

// 获取订单详情（需要认证）
app.get('/api/orders/:id', requireAuth, async (req, res) => {
  const { id } = req.params
  const userId = (req as any).userId

  try {
    // 查询订单详情，包括关联的客户、订单项和任务
    const { data: order, error } = await supabase
      .from('orders')
      .select(`
        *,
        customer:customers(*),
        items:order_items(*),
        tasks:order_tasks(*)
      `)
      .eq('id', id)
      .single()

    if (error) {
      console.error('查询订单错误:', error)
      return res.status(400).json({ error: error.message })
    }

    if (!order) {
      return res.status(404).json({ error: '订单不存在' })
    }

    // 获取用户角色以检查权限
    const { data: profile } = await supabase
      .from('profiles')
      .select('role')
      .eq('id', userId)
      .single()

    // 检查权限：管理员和办公室角色可以查看所有订单，其他角色只能查看分配给自己的任务相关的订单
    if (profile && !['admin', 'office'].includes(profile.role)) {
      // 检查该用户是否有此订单的任务
      const hasTask = order.tasks?.some((task: any) => task.assignee_id === userId)
      if (!hasTask) {
        return res.status(403).json({ error: '无权查看此订单' })
      }
    }

    res.json(order)
  } catch (error) {
    console.error('获取订单详情错误:', error)
    res.status(500).json({ error: '服务器内部错误' })
  }
})

// 获取订单列表（需要认证）
app.get('/api/orders', requireAuth, async (req, res) => {
  const userId = (req as any).userId
  const { status, page = 1, limit = 10 } = req.query

  try {
    // 获取用户角色
    const { data: profile } = await supabase
      .from('profiles')
      .select('role')
      .eq('id', userId)
      .single()

    let query = supabase
      .from('orders')
      .select(`
        *,
        customer:customers(name),
        items:order_items(id),
        tasks:order_tasks(id)
      `, { count: 'exact' })

    // 根据角色过滤数据
    if (profile && !['admin', 'office'].includes(profile.role)) {
      // 非管理员和办公室角色只能看到分配给自己的任务所在的订单
      const { data: userTasks } = await supabase
        .from('order_tasks')
        .select('order_id')
        .eq('assignee_id', userId)

      if (userTasks && userTasks.length > 0) {
        const orderIds = userTasks.map((task: any) => task.order_id)
        query = query.in('id', orderIds)
      } else {
        // 如果没有分配任务，返回空数组
        return res.json({
          data: [],
          count: 0,
          page: Number(page),
          limit: Number(limit)
        })
      }
    }

    // 状态过滤
    if (status) {
      query = query.eq('status', status)
    }

    // 分页
    const offset = (Number(page) - 1) * Number(limit)
    query = query
      .order('created_at', { ascending: false })
      .range(offset, offset + Number(limit) - 1)

    const { data: orders, error, count } = await query

    if (error) {
      console.error('查询订单列表错误:', error)
      return res.status(400).json({ error: error.message })
    }

    res.json({
      data: orders,
      count: count || 0,
      page: Number(page),
      limit: Number(limit)
    })
  } catch (error) {
    console.error('获取订单列表错误:', error)
    res.status(500).json({ error: '服务器内部错误' })
  }
})

app.listen(PORT, () => {
  console.log(`服务器运行在端口 ${PORT}`)
})

<script setup lang="ts">
import { ref, watch, nextTick, onMounted, onUnmounted } from 'vue'

// 定义组件属性
interface Props {
  visible: boolean
  imageUrl: string
  altText?: string
}

const props = withDefaults(defineProps<Props>(), {
  altText: '图片预览'
})

// 定义组件事件
const emit = defineEmits<{
  close: []
}>()

// 响应式状态
const overlayRef = ref<HTMLElement | null>(null)
const loading = ref(true)
const error = ref(false)

// 处理关闭事件
const handleClose = () => {
  emit('close')
}

// 处理图片加载成功
const handleImageLoad = () => {
  loading.value = false
  error.value = false
}

// 处理图片加载失败
const handleImageError = () => {
  loading.value = false
  error.value = true
}

// 处理键盘事件
const handleKeydown = (event: KeyboardEvent) => {
  if (event.key === 'Escape') {
    handleClose()
  }
}

// 监听visible变化，管理焦点和事件监听
watch(() => props.visible, (isVisible) => {
  if (isVisible) {
    nextTick(() => {
      // 聚焦到遮罩层以接收键盘事件
      overlayRef.value?.focus()
      document.addEventListener('keydown', handleKeydown)
      // 防止背景滚动
      document.body.style.overflow = 'hidden'
    })
  } else {
    document.removeEventListener('keydown', handleKeydown)
    document.body.style.overflow = ''
    // 重置状态
    loading.value = true
    error.value = false
  }
})

// 组件挂载时检查是否已有图片URL
onMounted(() => {
  if (props.visible && props.imageUrl) {
    loading.value = true
    error.value = false
  }
})

// 组件卸载时清理事件监听
onUnmounted(() => {
  document.removeEventListener('keydown', handleKeydown)
  document.body.style.overflow = ''
})
</script>

### 1. 后端代码 (server/src/index.ts) - **存在安全问题**

**问题：**
- **安全问题**：`requireAuth`中间件没有验证用户是否存在于`profiles`表中。JWT令牌可能来自已删除的用户或未完成注册的用户。
- **性能问题**：订单详情接口每次都会查询用户角色，即使已通过中间件验证。

// 验证 JWT（确保用户存在且有效）
async function requireAuth(req: express.Request, res: express.Response, next: express.NextFunction) {
  const authHeader = req.headers.authorization
  if (!authHeader?.startsWith('Bearer ')) {
    return res.status(401).json({ error: '未授权' })
  }

  const token = authHeader.slice(7)
  const { data: { user }, error } = await supabase.auth.getUser(token)

  if (error || !user) {
    return res.status(401).json({ error: '无效的令牌' })
  }

  // 验证用户存在于profiles表
  const { data: profile, error: profileError } = await supabase
    .from('profiles')
    .select('id, role')
    .eq('id', user.id)
    .single()

  if (profileError || !profile) {
    return res.status(401).json({ error: '用户不存在或未完成注册' })
  }

  ;(req as any).userId = user.id
  ;(req as any).userRole = profile.role
  next()
}
```
